# 6단계. 레시피 화면과 기록 화면

- 권장 모델: Haiku 5.5 / effort medium
- 이유: 이미 있는 데이터를 표시하는 단순 화면. 로직이 거의 없어 가장 저렴한 모델로 충분. 막히면 Sonnet으로 전환.
- 읽을 파일: `00-overview.md`, 이 파일, `src/types.ts`

## 작업
1. 레시피 탭: 메뉴 목록(요리 종류·단백질 필터, 이름 검색). 상세: 작업 시간·총 시간, 재료·분량, 조리 순서.
2. 기록 탭: 지난 주차 목록(최신순). 주차를 누르면 그 주 식단과 장보기목록 조회(읽기 전용).
3. 기록에서 메뉴를 골라 이번 주 특정 요일로 보내기 (4단계 교체 기능 재사용).

## 완료 기준
- 빌드 통과, 배포 확인. 1~6단계로 MVP 완성.

## 사용자 확인 필요 사항
1. 조리 중 레시피 화면 글자 크기·순서 표시가 보기 편한지.
2. 기록 화면에서 지난 주 메뉴를 이번 주로 가져오는 흐름 확인.
3. PR 승인·머지. 이 시점부터 실사용 시작 → 1~2주 사용 후 불편 사항을 알려 주면 7단계 전에 반영.
