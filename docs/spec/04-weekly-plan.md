# 4단계. 주간 식단 자동 추천과 "이번 주" 화면

- 권장 모델: Sonnet 5.5 / effort medium
- 이유: 제약 조건 알고리즘 + UI. 테스트로 검증 가능해 Opus 불필요.
- 읽을 파일: `00-overview.md`, 이 파일, `src/types.ts`, `src/db.ts`(또는 Dexie 정의 파일). 레시피 JSON은 읽지 않고 import만.

## 작업
1. `suggestWeek(library, history, weekStart, seed)`:
   - 최근 2주 메뉴 제외, 토·일은 totalMin ≤ 45인 메뉴만, 생선 ≥ 1, 한 요리 종류 ≤ 3, 같은 단백질 ≤ 3 (같은 단백질 연속 이틀 금지는 가능하면).
   - 조건을 못 맞추면 가장 덜 어긴 조합을 반환하고 어긴 규칙을 표시.
   - 평가 점수가 있으면 낮은 메뉴 가중치 감소 (8단계에서 데이터가 생김. 지금은 인터페이스만).
2. 교체 화면에서도 토·일에는 45분 초과 메뉴에 "주말 기준 초과" 표시 (선택은 허용).
3. "이번 주" 화면: 월~일 카드, "자동 추천" 버튼, 메뉴별 "교체"(라이브러리 검색 + 과거 주차 메뉴 목록에서 선택), 메뉴 누르면 레시피로 이동.
4. 다음 주로 넘어가면 지난 주 식단을 기록으로 보관.

## 완료 기준
- `suggestWeek` 단위 테스트: 시드 100개로 돌려 모든 규칙 충족률 보고 (규칙 위반 0이 목표).
- 빌드 통과, 배포 확인.

## 사용자 확인 필요 사항
1. 자동 추천 4주치 샘플 표(PR 본문에 첨부): 조합이 괜찮은지, 너무 자주 나오는 메뉴가 있는지.
2. 폰에서 "자동 추천" → "교체" 흐름이 쓰기 편한지.
3. PR 승인·머지.
