# 5단계. 장보기목록

- 권장 모델: Sonnet 5.5 / effort medium
- 읽을 파일: `00-overview.md`, 이 파일, `src/types.ts`, 2단계의 합산 함수 파일

## 작업
1. 주간 식단에서 장보기목록 생성 (2단계 합산 함수 사용). 매장 구역별 묶음, 구역 순서는 2단계에서 확정한 순서.
2. 체크하면 구역 안에서 아래로 이동·흐리게. 스와이프 또는 버튼으로 삭제(집에 있는 재료). 직접 항목 추가.
3. 상비 양념은 "집에 있는지 확인" 섹션으로 분리.
4. 메뉴 교체 시 자동 항목만 재계산. 직접 추가한 항목, 삭제 표시, 이미 체크한 동일 재료의 체크 상태는 유지.
5. 모든 동작이 오프라인에서 동작 (IndexedDB 즉시 저장).

## 완료 기준
- 재계산 로직 단위 테스트 (수동 항목·체크 유지).
- 비행기 모드에서 체크·추가·삭제 후 앱 재실행 시 유지.

## 사용자 확인 필요 사항
1. 실제 마트에서 1회 사용: 구역 순서, 글자 크기, 한 손 조작이 불편한 곳.
2. 표시된 수량이 사기에 이해되는지 (예: "당근 1.5개").
3. PR 승인·머지.
