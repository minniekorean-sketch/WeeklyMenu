# 8단계. 메뉴 평가·메모와 내보내기

- 권장 모델: Haiku 5.5 / effort medium
- 이유: 단순 입력 폼과 JSON 내보내기.
- 읽을 파일: `00-overview.md`, 이 파일, `src/types.ts`, 4단계 `suggestWeek` 파일(가중치 연결 부분만)

## 작업
1. 레시피 상세와 이번 주 카드에서 별점(1~5)·메모 입력. 날짜와 함께 저장.
2. `suggestWeek`에 평가 가중치 연결 (평균 2점 이하 메뉴는 추천 확률 크게 낮춤).
3. "내보내기": 평가·메모를 메뉴별로 모은 JSON 파일 다운로드. 메뉴 보충을 요청할 때 Claude에게 이 파일을 준다.
4. "가져오기": Claude가 만든 새 레시피 배치 JSON은 저장소에 커밋하는 방식으로만 추가 (앱 내 업로드 없음).

## 완료 기준
- 빌드·테스트 통과, 배포 확인.

## 사용자 확인 필요 사항
1. 평가·메모 입력이 장보기/요리 흐름을 방해하지 않는지.
2. 내보낸 파일이 열리는지.
3. PR 승인·머지.
